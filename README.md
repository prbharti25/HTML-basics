## How to Run

1. Clone or download this repository.
2. Open any `.html` file in a web browser.
3. For a smoother development experience, open the folder in VS Code and use the Live Server extension.

Each page is designed to work independently, so you can open the files directly without installing dependencies.

## Skills Practiced

- HTML document structure and boilerplate
- Headings, paragraphs, links, lists, tables, and images
- Forms and common input types
- Semantic HTML elements
- IDs, classes, and internal page navigation
- Basic multi-page website organization

## Notes

This is a learning repository. Some pages contain intentionally simple markup and placeholder content for practice. Form pages are front-end demonstrations only and do not process or securely store submitted data.

Before publishing publicly, replace or remove any personal contact information and review all sample data in the resume and contact pages.
